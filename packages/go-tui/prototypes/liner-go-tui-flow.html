North Star Flow Screens Patterns

o liner v2

The right context
for the right job.

This prototype tracks the Go Charm TUI direction. It is intentionally low fidelity: it documents information architecture, screen states, and language before polish.

Primary Flow

1. StartOpen an existing mixtape or create a new one.
2. SetupTitle, job to be done, curator, custom-source choice.
3A. SourcesIf yes, paste one item at a time. Enter adds it; f finishes.
3B. ClarifyIf no, go here directly. If yes, go here after sources are saved.
5. ResearchLiner runs the pass and reports what happened.
6. CompileCompile, preview, share, or reopen project assets.

Patterns

Boxes Are Structural

Use borders for active controls, tables, and side-by-side comparison. Avoid boxing read-only prose by default.

Clarification Is AI-Led

The AI reads the JTBD and returns targeted questions. If generation fails, the UI says so and lets the user continue.

Loader Voice

Keep the loader useful first: "AI is working on it." The rotating cassette lines add a small Liner-specific signature.
