The navigator is the terminal app. You talk to your agent, and you read here. Keep it open beside your chat, and it updates by itself as your agent works.

<CommandSnippet command="npx linersh" />

It never changes a liner. To act on something, press `y` to copy a prompt, then paste it into your agent.

## Library

The app opens on one table with four views. Press `1` to `4` to switch.

| View | What it shows |
| --- | --- |
| All | Every liner, with its job, state, sources, gaps, findings, and tests. |
| Attention | What's waiting for you, what has changed, and what could be stronger. |
| Sources | Your whole collection across every liner, by type and kind, and which liners use each source. |
| Connections | Which liners cite each other, and the sources they share. |

Press `space` to peek at a liner without opening it. In Sources, `t` and `k` filter by type and kind, and `s` sorts by name.

## Liner

Press `enter` to see everything one liner holds: its job, synthesis, sources by section, inbox, health, and files.

## Reader

Open any file to read it. In a synthesis, `tab` moves through the citations, `enter` follows one to its source, and `backspace` comes back.

Source files are evidence, not instructions, and they're marked that way.

## Search and handoff

Press `/` to search every liner, then `enter` to read a result. Press `y` from anywhere for prompts written for what's on screen. Nothing runs from the app.

## Keys

| Key | What it does |
| --- | --- |
| `1`-`4` | Switch views. |
| `enter` | Open or read. |
| `space` | Peek. |
| `/` | Search. |
| `y` | Copy a prompt for your agent. |
| `tab` | Next citation. |
| `o` | Open in your editor or browser. |
| `g` | Settings. |
| `esc` | Back. |
| `?` | Show every key. |
| `q` | Quit. |

## First run

With an empty library, the app offers to connect Claude Code or Codex by adding the `liner` skill, and gives you a prompt to start your first liner. To change the library folder, set `LINER_DIR` or `projects_dir` in `~/.liner/config.yaml`.
