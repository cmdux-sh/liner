## Check the installed version

<CommandSnippet command="npx linersh@latest --version" />

For version 1.2.0, the output is the following.

```text
liner 1.2.0 (tui) · 1.2.0 (core)
```

If the platform core binary cannot be resolved, the version command prints only the package version.

## Enable JavaScript rendering

If compile says a page is JavaScript-rendered or looks like a JavaScript app shell, and ends with "Install JS-rendering support: liner setup-js", the page needs headless Chromium. If it says "Playwright Chromium isn't installed yet", the browser download is missing. Either way, choose the command for your installation.

For one-shot use, run this command.

<CommandSnippet command="npx --yes linersh@latest setup-js" />

For a global install, run this command.

<CommandSnippet command="liner setup-js" />

## Fetch limits

Liner refuses to fetch an address on this machine, your local network, or a cloud metadata service, and it checks every redirect too. The error names the address and says how to allow it. Web pages and PDFs stop at 50 MB. If your sources live on an intranet or a Tailscale network, add this to `~/.liner/config.toml`.

```toml
[fetch]
allow_private_network = true
```

## Recover YouTube transcripts

YouTube can block transcript fetching for age-restricted, region-locked, or rate-limited videos. A Netscape-format cookies file can help when your browser session can access the video.

<CommandSnippet command="liner compile mobile-design-foundations --cookies ~/cookies.txt" />

You can also set the Core fetcher's default in `~/.liner/config.toml`.

## Help the navigator find the CLI

For local development, point the npm launcher at a specific CLI core binary.

<CommandSnippet command="LINER_BIN=/path/to/liner liner" />

The resolver tries `LINER_BIN`, the repo-local virtualenv, the bundled platform package, then `liner` on `PATH`.

## Reset local state

See [Uninstall](/docs/install/#uninstall) to review and remove Liner's local state and shared execution/browser caches. Saved Projects outside the removed paths remain in place.
