# Source Finding Tactics

Use this before Candidate discovery.

The goal is recall, not final judgment. Build a candidate pool that is wider than the final mixtape, then cut during Evaluation.

## Tactics

1. **Start with primary sources.** Specs, official docs, standards, canonical papers, manuals, and original talks beat summaries when they exist.
2. **Follow citations and references.** Strong sources usually point to older or more precise sources.
3. **Search by practitioner names.** If a field has recognized experts, search for their writing, talks, and bibliographies.
4. **Search for opposing positions.** If the domain has a debate, include sources from more than one credible side.
5. **Search YouTube deliberately.** Conference talks, lectures, demos, and interviews often contain dense context not available in articles.
6. **Ask for gaps, not just sources.** Given a candidate list, look for missing disciplines, missing primary documents, and missing counterarguments.

## Rules

- Verify that each URL exists before adding it to the long-list.
- Keep candidates grouped by knowledge-map section.
- Do not filter too early. If a source might matter, include it for Evaluation.
- Prefer specific source candidates over generic homepages.
